# بطل جدول الضرب - محمود 🌟

تطبيق تفاعلي للهواتف المحمولة مصمم خصيصاً للبطل **محمود (9 سنوات)** لتعلم وحفظ جدول الضرب بالنغمة المصرية العامية بطريقة ممتعة ومحفزة.

## 🚀 المميزات
- **النغمة المصرية:** قراءة وحفظ كل جدول بالنغمة الشعبية المألوفة (الواحد في اتنين باتنين.. الاتنين في اتنين بأربعة..).
- **تحدي الأبطال:** كويز تفاعلي بأزرار لمس كبيرة وأصوات تشجيعية مصرية خاصة بمحمود (عاش يا حودة!).
- **سباق السيارات:** لعبة سباق سيارات، كل مسألة يحلها صح تسبق سيارته خط النهاية.
- **شهادة التقدير:** شهادة كرتونية باسم محمود مع إمكانية الطباعة والحفظ.
- **تطبيق هاتف (PWA):** يعمل بدون إنترنت (Offline) ويُثبت على الشاشة الرئيسية للهاتف.
